Projeto para Estudo – Gestão de Ativos e Chamados de TI

Este projeto foi desenvolvido para fins de estudo com o objetivo de praticar modelagem de dados, criação de métricas e desenvolvimento de dashboards no Power BI.

A base de dados utilizada é fictícia e foi gerada com o auxílio do ChatGPT, simulando um cenário relacionado à área de TI.

🎯 Objetivo

Simular um ambiente de gestão de TI contendo:

Controle de ativos (equipamentos e status)

Gestão de garantias

Análise de investimentos

Monitoramento de chamados

Indicadores de performance do suporte técnico

O foco principal foi trabalhar a estruturação dos dados e a construção de indicadores estratégicos.

🗂️ Estrutura do Projeto

O dashboard está dividido em páginas temáticas:

🔹 Visão Geral

Total de ativos

Ativos em uso e em manutenção

Valor patrimonial

Distribuição por fabricante, tipo e localização

🔹 Garantia e Investimentos

Garantias ativas e vencidas

Ativos com garantia expirada

Investimento por tipo de ativo

Investimento por fabricante

🔹 Performance de Suporte

Total de chamados

Chamados resolvidos

Chamados ao longo do tempo

Chamados por prioridade

Chamados por técnico

🔹 Análise Detalhada

Chamados por tipo

Chamados por área responsável

Tabela detalhada com técnico, prioridade, status e tempo de resolução

🧠 Modelagem de Dados

O projeto utiliza:

Tabela de Ativos

Tabela de Chamados

Tabela Calendário (para análises temporais)

Relacionamentos 1:N entre as tabelas

Medidas em DAX para cálculos de KPIs

O foco foi aplicar boas práticas de modelagem e organização do modelo de dados.

🛠️ Ferramentas Utilizadas

Power BI

DAX

Modelagem de Dados

Base de dados fictícia gerada para estudo

Este projeto é exclusivamente para fins educacionais e não utiliza dados reais.
